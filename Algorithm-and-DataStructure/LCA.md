# 最近公共祖先

**最近公共祖先**（Lowest Common Ancestor, LCA）是指对于一颗**有根树**的两个节点 $u$ 和 $v$，他们的**公共祖先**中**深度最大**（即到两点距离最近）的那个节点。

求解最近公共祖先时，由于 $u$ 和 $v$ 两点的深度不一定相同，首先要**统一**深度。

假设 $u$ 节点深度较大，从该节点出发一路向上找到其与另一节点深度相同的祖先，并将该祖先设为新的 $u$ 节点。若新的 $u$ 节点和 $v$ 节点是同一个节点，则该节点即为最近公共祖先。

否则，两个节点同时出发不断上移，直到两节点**相遇**，即得到最近公共祖先。

极端情况下，当树退化成两条单链时，每次暴力求解的时间复杂度最坏可达 $O(n)$，非常不理想，需进行优化。

## 倍增法

对于两次向上爬升的跳跃次数，可以使用**倍增**法进行优化。

首先要预处理出从每个节点出发向上跳跃 $2$ 的若干次幂次之后可到达的祖先节点。

处理过程中，若每个节点的**深度信息**尚不得知，可一并处理。

```cpp
void build(int u, int father, int depth)
{
    depths[u] = deepth;
    ups[u][0] = father;
    for (int i = 1; i < m; ++i) // m 是倍增表中 2 的最大幂次，一般设为 ceil(log2(n)) + 1
    {
        ups[u][i] = ups[ups[u][i - 1]][i - 1];
    }
    for (int v : tree[u])
    {
        if (v == father)
            continue;
        build(v, u, deepth + 1);
    }
}

build(root, root, 1); // 将根节点的父节点设为本身，深度设为 1
```

预处理完成即可利用已有信息进行快速计算。

统一节点深度时，先计算出两节点间深度的差距。根据**二进制分解定理**，较低节点向上跳跃对应的距离。

```cpp
int calc(int u, int v)
{
    if (depths[u] < depths[v])
        swap(u, v);
    int dif = depths[u] - depths[v];
    for (int i = 0; i < m; ++i)
    {
        if (dif >> i & 1)
            u = ups[u][i];
    }

    if (u == v)
        return u;
    /*... ⬇️后续寻找 LCA 的代码 ...*/
}
```

节点深度统一之后，我们要让两个节点跳跃到距离最近公共祖先最近的点，即最近公共祖先的直接孩子节点。

设要跳跃的距离为一个未知数 $x$，根据**二进制分解定理**，对于每一个 $2$ 的幂次的距离，两点一定至多跳跃一次。若跳跃后两点到达相同点，则跳跃距离过大，放弃跳跃；否则跳跃该距离。最后返回两节点的直接父节点即为最近公共祖先。

由于 $x$ 是一个未知数，若从二进制低位开始遍历，不知道每一位是否要保留。只有从**高位向下**贪心选取时，才能找到恰好的每一位。

```cpp
int calc(int u, int v)
{
    /*... ⬆️统一深度的代码 ...*/
    for (int i = m - 1; i >= 0; --i)
    {
        if (ups[u][i] != ups[v][i])
        {
            u = ups[u][i];
            v = ups[v][i];
        }
    }
    return ups[u][0];
}
```

倍增法求最近公共祖先的时间复杂度为 $O(\log_2 n)$，额外空间复杂度为 $O(n \log_2 n)$。
