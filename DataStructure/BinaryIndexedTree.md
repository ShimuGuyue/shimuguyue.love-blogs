# 树状数组

**树状数组**（Binary Indexed Tree，又名**二进制索引树**）是对于**可差分**数据（加和、乘积、异或等，如求解区间总和）在**前缀和**维护的基础上，将前缀和数组根据二进制的一些性质，拆分成若干段区间进行**分段**维护，从而实现在大量的**修改**和**查询**操作交错进行时所有操作都能快速完成。

树状数组主要进行**单点修改-区间查询**的配套操作。但通过一些奇妙的**转换**，也可以实现诸如区间修改等更多特殊操作。

## 二进制分解

根据**二进制分解定理**，对于任意一个正整数 $n$，有 $n = 2^{k_1} + 2^{k_2} + \cdots + 2^{k_m}$，其中 $k_1 > k_2 > \cdots > k_m \geq 0$。

树状数组即是根据该定理，将前缀数组中任意第 $i$ 个位置的前缀和根据其二进制分解后的数值拆分成若干段。其中每个段中最末尾一个位置在树状数组中的值即为该段区间内的前缀和。

>   [!Tip]
>
>   由于 $0$ 的二进制中没有 $1$ 的存在，因此树状数组的构建应为**一基索引**。

根据分解定理，$i$ 位置维护的区间长度为其二进制分解后的**最小分解值**，即其二进制中最低位的 $1$ 所表示的大小（lowbit）。

查询前缀信息时，只需要将若干段 $2$ 的幂次长度的区间前缀信息进行**汇总**，即可得到结果。

>   对于 $i = 11$ 的位置，$i$ 的二进制表示为 $1011$，即 $8 + 2 + 1$。
>
>   因此将 $[1,\ 11]$ 位置的前缀分为长度分别为 $8,\ 2,\ 1$ 的三部分 $[1,\ 8],\ [9,\ 10],\ [11,\ 11]$。
>
>   三个区间的末位置二进制分别为 $1000$，$1010$ 和 $1011$，各自的 lowbit 值分别为 $8$，$2$ 和 $1$，即其各自维护的区间长度。

树状数组初始化时一般有两种方法：

1.   对每个位置分别进行单点修改操作，时间复杂度为 $O(n \log n)$，不需要额外空间；
1.   预处理出整个原始数组的前缀和数组，通过区间查询快速求出每个位置所维护的区间值，时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

## 区间查询

树状数组本质上还是特殊的前缀和数组，区间查询操作同理由区间首尾前缀值差分得到。

由于树状数组对前缀和进行了分段处理，求前缀信息的过程需要做出改变。

查询 $i$ 位置的前缀信息时，将其进行二进制分解得到若干个区间，对这些区间的前缀信息进行汇总即可得到 $i$ 位置的前缀信息。

查询每个区间末尾位置时，首先对 $i$ 求 lowbit 找到最近的一段区间长度，记录其区间信息后从总长中减去，即得到前一个区间的末尾位置。重复以上操作直到区间长度归零。

```cpp
int get_pre(int n)
{
    int ans = 0;
    while (n)
    {
        // 将答案与n位置维护的区间前缀信息进行汇总
        ans = ans + tree[n];
        // 区间右端点位置前移
        n -= lowbit(n);
    }
    return ans;
}
```

区间查询时，求出两个前缀值进行**差分**即得到答案。

```cpp
int query(int l, int r)
{
    return get_pre(r) - get_pre(l - 1);
}
```

查询操作的时间复杂度为 $O(\log n)$，无额外空间消耗。

---

进行单点查询时，可以有两种维护方法：

1.   将点 $n$ 视为区间 $[n,\ n]$ 进行区间查询，时间复杂度为 $O(\log_2 n)$；
1.   维护树状数组的同时也维护原始数组信息，查询时直接获取，时间复杂度为 $O(1)$。

## 单点修改

修改某个位置的信息时，需修改**所有**包含该位置的区间的信息。

对于位置 $i$，已知其作为右端点维护的区间长度为 $lowbit(i)$。由于树状数组中区间长度均为 $2$ 的幂次，所以包含位置 $i$ 的最小区间长度应为 $lowbit(i) \times 2$。所以 $i$ 距离更大的一个区间右端点的距离为 $i + lowbit(i)$。

得到了寻找更大区间的公式，即可从位置 $i$ 开始，不断向右寻找父区间右端点，直到超过数组大小。

```cpp
void update(int index, int data)
{
    while (index <= n) // n为区间总长度
    {
        tree[index] += data; 
        index += lowbit(index);
    }
}
```

# 拓展应用

## 区间修改 + 单点查询

树状数组用来处理的区间修改操作，一般是区间中每个数统一加上一个值。

对于这种操作，对原数组的前缀和很难进行区间维护，但由于查询操作是单点查询，那么可以将维护原始数组的前缀和更改为维护**原始数组的差分数组**。

区间修改时，只需要对差分前缀的区间首尾分别进行单点修改即可。单点查询时，返回差分数组的前缀和即为答案。

## 区间修改 + 区间查询

当对区间同时进行区间修改和区间查询操作时，维护单个的前缀差分数组不再能完成任务，但可以通过**公式转化**得到可以用树状数组维护的数据类型。

$$
\begin{aligned}

\because   pre(n) &= \sum_{i = 1}^{n} a_i = a_1 + a_2 + \cdots + a_n,\\
              a_i &= \sum_{j = 1}^{i} dif(j),\\
\therefore pre(n) &= \sum_{i = 1}^{n} \sum_{j = 1}^{i} dif(j)\\
                  &= \sum_{i = 1}^{n} dif(i) \times (n - i + 1)\\
                  &= \sum_{i = 1}^{n} dif(i) \times n + \sum_{i = 1}^{n} dif(i) \times (i - 1).

\end{aligned}
$$

由此变换可得，需要进行区间查询时，只需要对两种前缀信息分别维护，然后运算即可得到答案。
